# 習題 3（第 3 週構想 + 第 8 週實作）：DeadlineMate 課表 + 作業截止提醒

> 第 3 週：想出一個有價值的專案程式
> 第 8 週：回到習題 3，把它實作出來

## 一、為什麼有價值？

### 使用價值 —— 我自己就是使用者

大學生每學期修 7~9 門課，作業公告散落在：

* 老師的 GitHub issue（像這門課）
* Moodle / 校務系統
* LINE 群組、課堂口頭說明

結果常常是「**忘記交**」或「**最後一晚才發現三份作業同一天截止**」。我需要的其實很簡單：

1. 打開就看到**下一堂課在哪**、**今天有什麼要交**
2. 新增作業要**快**（一句話就加好，不想填表單）
3. 能進手機行事曆，**自動提醒**

現有工具的問題：Google 日曆要一個一個填、沒有課表概念；Notion 太重；學校系統不會整合不同老師的作業。

### 商業價值

方向 | 說明
-----|-----
免費增值 (Freemium) | 個人版免費；進階版提供 LINE / Telegram 推播、跨裝置同步、AI 讀公告自動抓截止日（月費 30~50 元）
學校 / 系所授權 | 系辦可以統一發布作業與考試時間，學生一鍵訂閱，減少「沒看到公告」的爭議
接案 | 補習班、線上課程平台需要的「課程 + 作業提醒」模組可以直接改做
數據 | 匿名統計「哪一週作業最多」，可以回饋給系所調整課程安排

## 二、功能

功能 | 說明
-----|-----
**總覽儀表板** | 下一堂課 / 正在上的課、待完成數、逾期數、24 小時內截止數、未來四週作業量長條圖、今天的課
**一句話快速新增** | `軟工 HW3 11/15 23:59`、`資結 lab5 下週三`、`網頁 作業2 明天`、`繳學費 3天後`
**課名縮寫比對** | 「軟工」→ 軟體工程、「資結」→ 資料結構、「計結」→ 計算機結構（字依序出現即可）
**緊急度分色** | 已逾期 🔴 / 24 小時內 🟠 / 3 天內 🟡 / 7 天內 🔵 / 之後 ⚪
**週課表** | 依節次畫格子，格子上顯示該課還有幾份作業沒交；點一下可編輯
**衝堂檢查** | 新增課程時若時間重疊會警告，可強制儲存
**匯出行事曆 (.ics)** | 課程每週重複 18 週；作業截止前 1 天、1 小時提醒。可以「訂閱網址」到 Google 日曆或 iPhone
**瀏覽器通知** | 網頁開著時，24 小時 / 1 小時前跳通知（同一份不重複通知）
**深色模式** | 跟隨系統

## 三、執行

不需要安裝任何套件（只用 Python 標準函式庫）：

```bash
python app.py
```

打開 <http://localhost:8080>，第一次啟動會放入示範課表與作業。刪掉 `deadline.db` 就能重置。

## 四、架構

```
hw3/
├── core.py          純邏輯：緊急度、剩餘時間、下一堂課、衝堂、一句話解析、.ics 產生、每週作業量
├── app.py           HTTP 伺服器 + SQLite + REST API
├── public/index.html 前端（原生 JS 單頁應用）
└── test_app.py      單元測試 + API 測試（17 個）
```

把「邏輯」和「HTTP」分開，`core.py` 不碰資料庫、不碰網路，所以可以直接單元測試（時間也是用參數傳入，測試不會因為今天日期不同而失敗）。

### API

方法 | 路徑 | 說明
-----|------|-----
GET | /api/dashboard | 總覽資料
GET / POST | /api/courses | 課程列表 / 新增（衝堂回 409，加 `?force=1` 強制）
PUT / DELETE | /api/courses/{id} | 修改 / 刪除
GET / POST | /api/assignments | 作業列表（含 urgency、remaining）/ 新增
PUT / DELETE | /api/assignments/{id} | 修改（例如 `{"done":true}`）/ 刪除
POST | /api/quick | 一句話新增 `{"text":"軟工 HW3 明天"}`
GET / PUT | /api/settings | 學期開始日
GET | /calendar.ics | iCalendar 訂閱

### 資料表

```sql
courses(id, name, code, teacher, room, day, start_period, end_period, color)
assignments(id, course_id, title, due, note, priority, done, created_at)
settings(key, value)
```

## 五、測試

```bash
python -m unittest test_app -v
```

測試項目：緊急度分級、剩餘時間文字、下一堂課（含正在上課）、衝堂、一句話解析（絕對日期、明天、N 天後、週三 / 下週三、跨年、錯誤輸入）、.ics 內容與跳脫字元、每週作業量、作業 CRUD、欄位驗證、課程衝堂 API、.ics 端點、靜態網頁。
